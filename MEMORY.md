# Dark Fantasy Survivor — Build Memory

The WebDev scaffold is React 19 + Vite + Tailwind 4. Three.js 0.185 is installed. The requested Fable modules live under `client/src/game-fsharp/`; the immediate browser runtime is TypeScript because the static scaffold does not include a .NET/Fable compiler pipeline.

The built-in image generation calls returned reserved URLs whose visible placeholders reported generation failure during screenshot capture. The runtime therefore uses an explicit procedural charcoal/umber floor texture and a CSS-rendered broken-halo mark rather than presenting failed placeholders as finished art. The generated references remain recorded in `ASSETS.md` for a later texture-atlas pass if the assets become available.

The visual review requested stronger material depth, custom mark presence, manuscript motifs, readable silhouettes, and ceremonial copy. A cohesive revision added procedural cathedral-floor geometry, a larger broken-halo mark, engraved meter treatment, parchment-like ritual cards, heavier relic surfaces, and more custom-feeling wordmark styling.
